# 수상레저종합정보 AI 도우미 (시연용)

수상레저종합정보 메인화면에서 민원인이 말로 입력하면 해당 화면으로 안내하고, 궁금한 점은 IRQA 시트를 근거로 답하며, 원거리 수상레저활동 신고서는 출항 계획 문장으로 초안을 작성해 주는 챗봇의 **시연용 목업**입니다. 공식 포털 화면이 아니며 실제 신고는 접수되지 않습니다.

## 실행
`index.html`을 브라우저로 열면 됩니다. (서버·설치 불필요)

- 같은 폴더의 `irqa-data.js`가 있으면 IRQA 시트(질문 56건·유사질의 291건)를 근거로 답합니다. 없으면 내장 샘플 3건으로 동작합니다.
- 챗봇 상단 **설정**에서 Anthropic API 키를 넣으면 **LLM 모드**, 비우면 규칙·키워드 기반 모드로 동작합니다.
- 챗봇 상단 **IRQA 시트**로 CSV(질문, 유사질의, 답변, 답변수정 열)를 불러와 교체할 수도 있습니다.

## 동작 방식 (LLM 모드)
1. 시스템 프롬프트에 화면 목록과 IRQA 시트 전체(약 2.2만 자)를 넣고 프롬프트 캐시를 겁니다.
2. 모델이 도구 하나를 호출해 응답합니다: `answer`(시트 근거 답변) · `navigate`(화면 안내) · `fill_far_report`(신고서 항목 추출) · `clarify`(되묻기) · `no_answer`(표준 안내 문구) · `chat`(인사 등).
3. 화면은 모델이 준 값을 검증(허용 목록·형식·범위)한 뒤에만 반영합니다. 시트에 없는 근거 id나 화면 id는 버립니다.
4. API 호출이 실패하면 규칙 기반 모드로 자동 전환해 시연이 끊기지 않게 합니다.

## 보안·운영 주의
- API 키는 탭 세션(sessionStorage)에만 저장되며 코드·저장소에 포함되지 않습니다. 브라우저에서 직접 호출하는 구성은 **시연용**입니다. 실제 서비스는 서버 프록시(키 보관, 호출 제한, 로그 정책)와 기관이 승인한 모델 환경이 필요합니다.
- LLM 모드에서는 시트 내용과 민원인 입력이 API로 전송됩니다. 개인정보(주민등록번호 등)는 입력하지 않도록 안내하세요.
- `irqa-data.js`는 IRQA 시트에서 추출한 질문·답변 데이터입니다. 공개 정보로 판단해 함께 올렸으며, 시트가 바뀌면 이 파일만 교체하면 됩니다.
- 신청인 정보는 가상 데이터이며, 해양경찰청 엠블럼·로고는 사용하지 않았습니다.
