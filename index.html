    하고 싶은 일을 입력하면 AI 도우미가 해당 화면으로 안내하고, 궁금한 점은 바로 답해 드립니다.

    시연 안내
    ① 민원 이동하고 싶은 일을 말하면 해당 신청·조회 화면으로 안내합니다.
    ② 신고서 자동작성원거리 신고 계획을 문장으로 말하면 신고서 초안을 채웁니다. 확정은 이용자가 합니다.
    ③ 궁금증 답변(RAG)IRQA 시트를 근거로 답하고, 근거 행 번호를 함께 보여 줍니다.
    • 답변 근거는 IRQA_20260810_1 시트(질문 56건·유사질의 291건)입니다. 「답변수정」 열이 있으면 그 내용을, 없으면 「답변」 열을 쓰고, 답이 없는 질문은 시트에 적힌 표준 안내 문구를 보여 줍니다. 채팅창 상단 「IRQA 시트」로 CSV를 불러와 교체할 수도 있습니다.
    • 화면 이동은 원거리 신고만 이 시연 안에서 열리고, 나머지는 실제 포털 해당 페이지가 새 탭으로 열립니다.
    • 챗봇 설정에서 Anthropic API 키를 넣으면 LLM 모드로 동작합니다. 시트 전체와 화면 목록을 모델에 제공하고, 모델이 답변·화면 이동·신고서 작성 중 하나를 골라 응답합니다. 키가 없으면 규칙·키워드 기반 모드로 동작합니다.
